# Калькулятор и конвертер

Flutter Web: калькулятор, конвертер пяти валют, результат по URL и страница 404.
Используется Flutter 3.50 / Dart 3.14, go_router и material_ui.

## Запуск и проверки

```sh
flutter pub get
flutter analyze
flutter test
flutter run -d chrome
flutter build web
```

## Маршруты

- `/` — главная.
- `/calculator` — четыре арифметические операции.
- `/calculator/result?a=10&op=%2B&b=5` — результат 15.
- `/converter` — конвертер с фиксированными учебными курсами.
- `/converter/result?amount=2&from=USD&to=RUB` — результат 180 RUB.
- Любой неизвестный путь — экран 404.

Результат самостоятельно читает query-параметры текущего URL: данные не передаются через extra или конструктор. Знак плюса в URL кодируется как `%2B`. Отсутствующие, повторяющиеся и некорректные параметры показывают ошибку. Числа могут содержать точку или запятую; NaN, Infinity и переполнение отклоняются.

Логика находится в `lib/logic`, настройки — в `lib/settings.dart`, экраны — в `lib/screens`. Тема и пара валют сохраняются через shared_preferences. Формы ограничены шириной и прокручиваются при нехватке высоты.

## Размещение на сервере

Готовые файлы находятся в `build/web`. Для path URL strategy сервер должен возвращать `index.html` для путей приложения, если физического файла нет. Например, для nginx в блоке location /:

```nginx
try_files $uri $uri/ /index.html;
```

Без такого правила обновление страницы результата на обычном статическом сервере может дать серверную 404 до загрузки Flutter.

## Ручная проверка в браузере

1. Главная → калькулятор → результат; кнопки браузера «Назад» и «Вперёд» возвращают соответствующие экраны.
2. Открыть ссылки результата в новой вкладке и обновить страницу.
3. Проверить отсутствующие параметры, деление на ноль и `/qwerty`.
4. Переключить тему и пару валют, обновить страницу: настройки восстановлены.
5. Проверить ширины 360 и 1920 пикселей.

Автоматические тесты проверяют вычисления, ошибки, округление, восстановление настроек, прямые маршруты, валидацию форм и отсутствие ошибок раскладки на обеих ширинах. Браузерная история и фактическая перезагрузка вкладки требуют отдельной ручной проверки.
